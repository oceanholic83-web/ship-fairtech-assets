## 톤수 단위 — 관청 시설표를 읽는 법

**부두마다 접안능력 단위가 다르다.** 표의 「행」과 「단위 칸」을 함께 보지 않으면 다른 부두 수치를 가져오게 된다.

| 대상 | 단위 | 예 |
|---|---|---|
| 컨테이너부두 | **TEU** | 4천 TEU급 |
| 벌크·원유·원료부두 | **DWT** | 35만 DWT |
| 여객선·카페리·크루즈 | **GT** | 8만 GT급 크루즈 |
| 묘박지 | 관청 표에 따라 **GT** 인 경우가 많다 | 50,000 GT × 10척 |

**사고 이력 2건**
- 군산항 초안(2026-07-26): 묘박지 표의 **GT 를 DWT 로 읽었다**
- 광양·여수 발행분(2026-08-23): **원료부두 DWT(30만)** 를 **컨테이너부두** 문장에 붙였다. 컨테이너선에 30만 톤급은 존재하지 않는다

→ 같은 실패가 초안과 발행분에서 반복됐다. **관청 표 인용 시 행·단위를 함께 기록한다.**

## 선박명 표기

공식 글에서 「○○호」만 쓰면 어색하다. **첫 등장에 영문을 병기한다.**

| 대상 | 표기 |
|---|---|
| 한글 선명 | `나무(Namu)호` · `한국케미(Hankuk Chemi)호` · `시프린스(Sea Prince)호` |
| 영문 선명 | `Dali` 그대로. 굳이 한글 음차하지 않는다 |
| 선사 접두 | `HMM 나무(Namu)호` — 선사명은 앞에 붙인다 |
| 두 번째 등장 | 한글만 (`나무호`) |

조선소·기업명은 선박명이 아니다. `HD현대삼호` 는 병기 대상이 아니다.

## 「틀리다」 사용 제한

「틀리다」는 **정답이 있는 사실 판정**에만 쓴다. 아래는 전부 오용이다.

| 오용 | 대체 |
|---|---|
| 시장이 **틀린** 게 아니다 | 시장이 **잘못 읽은** 게 아니다 |
| 2030년에 **틀린** 선택 | 2030년에 **잘못된** 선택 |
| 매수자가 **틀리면** | 매수자가 **잘못 판단하면** |
| 그렇게 읽으면 **틀립니다** | 그렇게 읽으면 **사실과 어긋납니다** / **단정하기 어렵습니다** |
| **틀린** 말은 아니다 | **맞는** 말이다 |

2026-08-23 전수 소거: 발행글 6편에서 검출, 전부 교체.

## 판단 기준

새 용어를 정할 때는 이 순서로 확인한다.

1. 법령·고시 (선박안전법, 해양수산부 고시)
2. 기관 공식 문서 (한국선급, IMO/IACS 국문본, 항만공사)
3. 한국 업계 매체에서 실제로 쓰이는가 — 네이버 뉴스 검색으로 확인
4. 영문 원문 직역은 **마지막 수단.** 「재가격(reprice)」 같은 조어 금지

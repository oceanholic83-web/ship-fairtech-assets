# 이식 정책 — fairwayeta(영문) → faircast(한글)

faircast.kr 의 상당수 글은 fairwayeta.com 영문 글을 바탕으로 한다.
이때 **번역이 아니라 재작성**이다. 이 문서는 그 경계를 정의한다.

원장은 `claude/PORT_MAP.tsv`. 이 문서는 그 원장을 어떻게 채우는지에 대한 규칙이다.

---

## 1. 원칙 — 유지하는 것과 버리는 것

| 유지 | 버리는 것 |
|---|---|
| **구조** — 섹션 순서, h2 뼈대, 논지 전개 | 영문 문장·단락 구조 |
| **thesis** — 글이 주장하는 바 | 영어 어순·수동태·관계대명사 |
| **데이터·고유명사** — 수치, 항만명, 선형명, 지수명 | 영문 표현 그대로의 어휘 |
| **이미지·도식의 내용** | Tailwind 클래스 기반 마크업 |

⚠️ **단순 번역 금지.** 영문 원본을 옆에 띄워놓고 문장 단위로 옮기면 반드시 번역체가 나온다.

### 2단 분리 작성법 (지침 [5.5])

1. 영문 원본에서 **데이터 · 고유명사 · thesis · 섹션 뼈대만** 한국어 메모로 추출
2. 영문 원본을 **닫는다**
3. 메모만 보고 한국어로 자체 작성

번역체 5대 패턴과 트리거 단어 8개 자가 점검은 지침 [15]. 특히 이것들:
`~에 의해` · `~을 위해서` · `~에도 불구하고` · `~라는 사실` · `~함에 있어` ·
명사+의+명사 3중첩 · 문장 첫 단어 `이`/`그` · 콜론 직접 옮긴 절

## 2. 필수 절차 — 발행 전 3단 조사

원본이 있다고 조사를 건너뛰지 않는다. **영문 원본은 초안의 재료이지 근거가 아니다.**

### (1) 현업 용어 조사

영문 개념을 한국 해운·조선·항만 실무자가 실제로 부르는 말로 바꾼다.
직역 조어를 만들지 않는다. 확인 순서는 `docs/NAMING_POLICY.md` 「판단 기준」 과 동일하다.

1. 법령·고시 (선박안전법, 해양수산부 고시)
2. 기관 공식 문서 (한국선급 KR, IMO/IACS 국문본, 항만공사, 해운협회)
3. 한국 업계 매체에서 실제로 쓰이는가 — 네이버 뉴스 검색으로 확인
4. 영문 직역은 **마지막 수단**

판정 기준 한 줄: **네이버 뉴스에서 검색되는 표현인가.**

첫 등장 표기는 `한국어(약어, 영문 풀네임)` 형식. 선형 명칭(Capesize, Panamax 등)처럼
국내에서도 영문 그대로 쓰는 것은 억지로 한글화하지 않는다.

### (2) 한국 자료 보강

영문 원본에 없는 **한국 anchor 1~2개**를 반드시 넣는다. 없으면 한국 독자에게 남의 이야기다.

찾는 것:
- 한국 항만·선사·조선소가 이 주제와 닿는 지점
- 국내 통계 (해양수산부, 항만공사, KMI, 한국선급)
- 국내 규제·제도상의 차이

### (3) 최신성 검증

**영문 발행 시점과 한글 발행 시점 사이의 간극을 메운다.**
영문 원본이 몇 달 전 데이터를 쓰고 있으면 그 수치는 이미 낡았을 수 있다.

- 시황·지수·운임 (BDI, SCFI, WS, TCE, 용선료) → **반드시 최신본 재조회**
- 선대·발주 잔량 → 분기 갱신본 확인
- 규제 시행일·단계 → 발효 여부와 다음 단계 일자 재확인
- 사건·정책 → 그 뒤에 뒤집힌 것이 없는지 확인

수치를 옮길 때는 **기자 해석이 아니라 1차 출처**를 본다 (지침 [18]).

### (4) 도식·이미지 정합성

이미지에 박힌 수치와 본문 수치가 어긋나면 현업 독자가 바로 잡아낸다.
**어긋나면 이미지 쪽에 본문을 맞춘다** (이미지 재생성이 더 비싸다).

관청 표에서 톤수를 가져올 때는 행과 단위 칸을 함께 기록한다 — `NAMING_POLICY.md` 「톤수 단위」.

## 3. 재활용 자산

영문 원본 `.tsx` 에서 가져오는 것.

| 자산 | 위치 | 처리 |
|---|---|---|
| 이미지 | `ship-eta-calculator/public/images/insights/*.webp` | `faircast-images/img/` 로 복사 → **새 태그** (v2, v3…) → jsDelivr |
| 도식 (CSS 차트) | `.tsx` 안 `{/* CHART n */}` 블록 | Tailwind 클래스는 **못 쓴다.** 내용만 가져와 지침 [8] 다크박스 인라인 스타일로 재작성 |
| 인라인 SVG | `.tsx` 안 `<svg>` | 그대로 이식 가능. 라벨만 한글화 |

이미지에 영문 라벨이 있어도 **선형·부위 명칭이면 그대로 둔다.** 국내 현업도 영문으로 부른다.
번역해야 하는 것은 서술형 문장 라벨뿐이다.

⚠️ **태그를 새로 파지 않으면 CDN 이 새 파일을 못 본다.** 불변 태그라 캐시가 갱신되지 않는다.

```
cd faircast-images
git add img
git commit -m "add <topic> article images (N)"
git tag vN
git push origin main --tags
```

발행 전 실제 URL 200 확인:

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" "https://cdn.jsdelivr.net/gh/oceanholic83-web/faircast-images@vN/img/<name>.webp"
```

## 4. 원장 규칙 (`claude/PORT_MAP.tsv`)

| status | 뜻 |
|---|---|
| `DONE` | 이식·발행 완료. `fc_slug` 필수 |
| `WAIT` | 이식 대상. 아직 안 함 |
| `SKIP` | 이식하지 않기로 **판정 완료**. 다시 검토하지 않는다 |
| `HOLD` | 판정 보류. 한글판에 흡수됐는지 확인이 필요 |

### SKIP 기준 — 상시 자산만 옮긴다

- **단발 사건 분석** — 특정 사고·회의·정치 국면. 발행 시점이 지나면 죽은 글
- **시황 스냅샷** — "지금 사이클 어디쯤" 류. 몇 달 뒤 틀린 글이 된다
- **한국 독자 무관** — 미국 국내 무역·관세 이슈 등
- **자사 도구 홍보** — 한글 사이트에 대응 도구가 없으면 의미 없음

남기는 것은 **1년 뒤에도 검색되는 글**이다. 제도 설명, 선형·톤수 정의, 항로 구조, 기초 개념.

### 원장 갱신

```
powershell -ExecutionPolicy Bypass -File scripts\port-map.ps1
```

새 영문 글은 `WAIT` 로 자동 추가된다. `hint` 열은 **제안일 뿐이다.**
**자동으로 `DONE` 이 되는 일은 없다.** 사람이 확인하고 손으로 적는다.

## 5. 발행 전 체크리스트

지침 [5.1] 워드프레스 항목에 더해, 이식 글은 아래를 추가로 확인한다.

- [ ] 영문 원본을 닫고 썼는가 (2단 분리)
- [ ] 트리거 단어 8개 검색 — 0건인가
- [ ] 현업 용어 조사 완료 — 네이버 뉴스에서 검색되는 표현인가
- [ ] 한국 anchor 1~2개 들어갔는가
- [ ] 시황·지수·규제 일자 **최신본으로 재조회**했는가
- [ ] 이미지 수치와 본문 수치가 일치하는가
- [ ] jsDelivr 새 태그 URL 200 확인했는가
- [ ] 인용구(따옴표 직접 인용) 0개인가
- [ ] 출처 2~3개 한 줄인가
- [ ] `PORT_MAP.tsv` 에 `DONE` + `fc_slug` 기록했는가

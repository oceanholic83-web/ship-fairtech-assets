|---|---|---|

구글이 이 도메인에 대해 들고 있는 URL 목록의 3분의 1 이상이 축구 예측 사이트 시절의 것이다.
마지막 크롤이 2026-08-16 — **여전히 재크롤 중**이며, 410 전환(8/14)이 아직 반영되는 단계다.

**410은 정상 작동한다** (2026-08-22 실측):

```
/insights/world-cup-2026-squad-announcement-schedule  410
/match/croatia-vs-ghana                               410
/simulate/france                                      410
/tournament /rankings /matchup /simulate              410
```

### 예외 1건 — 고칠 것

```
/insights   →  홈으로 301  (200)
```

맨 경로 `/insights` 만 홈 301이 남아 있다. **8/14에 확인한 그대로, 홈으로 보내는 301은 soft 404 취급이라 색인에서 안 빠진다.**
406 스니펫에 이 경로를 추가해 410으로 바꾼다.

## 3. 진짜 문제 — 발행글 45편이 「읽었지만 안 넣음」

「크롤링됨 – 현재 색인이 생성되지 않음」 91건의 내역:

| 분류 | 건수 |
|---|---|
| **실제 발행글·페이지** | **45** |
| 월드컵 잔재 | 27 |
| 카테고리 아카이브 (noindex, 정상) | 8 |
| feed · 페이지네이션 · tag feed | 8 |
| `wp-emoji-release.min.js` | 1 |

여기에 「발견됨 – 색인 안 됨」 5편이 더 있다.

```
17 색인 + 45 크롤됐지만 거부 + 5 발견만 = 67 ≈ 사이트맵 69
```

**사이트 전체가 크롤은 되고 색인에서 거부되는 상태다.** 「크롤링됨 – 색인 안 됨」은 크롤 실패가 아니다.
구글이 페이지를 **읽고 나서** 색인에 넣지 않기로 판정한 것이며, 기술적 접근 장애로는 설명되지 않는다.

거부된 45편에는 항만 시리즈 전편, VLCC 시리즈 3편, 규제 시리즈가 모두 포함된다. 특정 유형의 문제가 아니다.

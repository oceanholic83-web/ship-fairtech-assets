# data/ports — 항만 1차 자료

수집: 2026-08-23 · 방식: 크롬으로 각 지방해양수산청 공식 페이지 직접 조회
(WebFetch 는 mof.go.kr robots 에 막힌다. 브라우저로만 읽힌다.)

## 출처 권위 — 항마다 다르다

| 항 | 1차 출처 | 비고 |
|---|---|---|
| 동해·묵호 | 동해지방해양수산청 | **완전**. 물동량 2012~2025, 항만구역 밖 시설 포함 |
| 울산 | 울산지방해양수산청 | **완전**. 본항/온산/미포/신항 4개 구역 선석 전수 |
| 평택·당진 | 평택지방해양수산청 | **완전**. 동/서/고대/송악부두 + 돌핀부두 운영사별 |
| 포항 | 포항지방해양수산청 | 항세 + 영일만항 선석. 신항 38선석 상세는 미수집 |
| 목포 | 목포지방해양수산청 | 항세 + 부두별. 대불 자유무역지역 정보 포함 |
| 군산 | 군산지방해양수산청 | **완전**. 부두별 접안능력·하역능력·운영주체 |
| 마산 | 마산지방해양수산청 | 2026 예산만. 항세·선석 미수집 |
| 대산 | 대산지방해양수산청 | 항세·연혁. 선석 상세 미수집 |
| 부산 | **부산항만공사(BPA)** | 지방청 페이지가 얕다. 컨테이너 물동량만 확보 |
| 인천 | **인천항만공사(IPA)** | 지방청 물동량이 2022년까지. IPA 로 갱신 필요 |
| 여수·광양 | **여수광양항만공사(YGPA)** | 원료부두 선석 확보. 컨테이너·전체 물동량 미수집 |

⚠️ **항만공사가 있는 4개 항(부산·인천·여수광양·울산)은 공사 자료가 최신이다.**
지방청 페이지는 갱신 주기가 느리다. 인천은 2022년 자료가 그대로 걸려 있다.

## 공통 주의

- **접안능력 단위가 부두마다 다르다.** 화물부두 DWT / 컨테이너부두 TEU / 여객부두 G/T.
  같은 표에서 행을 잘못 읽으면 컨테이너선에 30만 톤급이 들어온다는 문장이 나온다.
- **항만구역 밖 항만시설**을 반드시 함께 본다. 발전소·제철소 전용부두가 무역항 통계에서 빠진다.
  동해가 대표 사례이고, 평택 송악(현대제철)·포항도 같은 구조다.
- 페이지 캡션의 연도 표기가 실제 연도와 다른 경우가 있다 (마산 2026 예산 페이지의 표 캡션이 「2023년도」).

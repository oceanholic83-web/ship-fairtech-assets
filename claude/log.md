## [2026-08-22] 정정 | 정규식이 맞아도 차례가 안 오면 안 돈다 — 406 훅 우선순위

| 경로 | 수정 전 |
|---|---|
| `/insights/group-e-preview` | 410 ✅ |
| **`/insights` · `/insights/`** | **200 → 홈** ❌ |
| `/tournament` `/match/...` `/simulate` | 410 ✅ |

406 의 정규식 `#^/insights(/.*)?$#` 은 맨 경로를 정확히 잡는다. **문제는 거기까지 도달을 못 한 것.**

`/insights` 는 **Insights 카테고리 슬러그와 충돌**한다. 워드프레스 코어가 `/insights` → `/category/insights/` 로 정규화하고, **494(Category→Page 301)** 가 그걸 홈(`insights-landing`, post 269)으로 넘긴다.

→ **`add_action(..., 1)` 로 우선순위만 지정.** 코드 본문은 한 글자도 안 고쳤다.

## [2026-08-22] 작업 | 푸터 저작권·AI 고지 추가 (AdSense 조치 2/4)

```
분석과 본문은 편집팀이 1차 자료를 바탕으로 작성합니다. 본문 이미지는 편집팀이 제작·선별했으며 일부는 AI 도구를 사용했습니다.
```

**AI 고지는 이미지에만 한정하고, 같은 자리에서 본문은 편집팀 작성임을 밝힌다.**
구글 스팸 정책은 AI 사용 자체를 금지하지 않는다. 금지 대상은 「가치 없는 페이지 대량 생산」(scaled content abuse)이고 판정 기준은 제작 방법이 아니라 의도와 가치다.
미고지가 더 위험하다 — 실사로 보이는 AI 이미지에 아무 표시가 없으면 오해를 유발한다.
다만 「가치가 별로 없는 콘텐츠」로 4회 거절당한 사이트가 「AI로 씁니다」로 읽히는 문구를 다는 건 자해다. 그래서 범위를 이미지로 좁혔다.

**위치 — 위젯이 아니라 Kadence 푸터 빌더**

`widgets.php` 의 Footer 1~6 은 이 테마에서 안 쓰인다. 실제 푸터는 Kadence 커스터마이저의 행(Row) 구조다.

| 설정 | 값 |
|---|---|
| 요소 | Bottom Row 의 **Copyright**(내부 id `footer-html`) |
| `footer_html_content` | 위 2줄 (`<span style="display:block">` 로 줄 분리) |
| `footer_html_typography` | 12px / `#94a3b8` / 행간 1.7 |
| `footer_top_bottom_spacing` | 30 → **8** |
| `footer_middle_top/bottom_spacing` | 30/30 → **0/0** (빈 행이 자리만 먹고 있었다) |
| `footer_bottom_bottom_spacing` | 30 → 24 |

검증: 데스크톱·모바일(390px) 양쪽 육안 확인. 태그 노출 없음.

## [2026-08-22] 정정 | Kadence Copyright 필드는 HTML 을 이스케이프한다 — 요소를 착각했다

처음에 `<div><p>` 로 4줄을 넣었더니 **태그가 글자 그대로 출력**됐다.
`+` 메뉴에 `HTML` 항목이 없어 `COPYRIGHT` 를 골랐는데, Kadence 무료판의 이 요소는 표시 이름만 Copyright 이고
설정 키는 `footer_html_*` 다. **`footer_html_content` 는 HTML 을 그대로 렌더한다** — 문제는 요소가 아니라 처음에 순수 텍스트로 넣었다가 다시 태그를 섞은 순서였다.

교훈: **테마 요소는 표시 이름이 아니라 설정 키(`wp.customize` id)로 판별한다.**

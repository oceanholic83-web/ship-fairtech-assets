# FACT_SOURCES — 사실 검증 출처 원장

**신설 2026-08-04**

**같은 출처를 두 번 헤매지 않기 위한 문서다.**
어느 1차 출처가 열리고 안 열리는지, 무엇을 담고 있는지, 어떻게 읽어야 틀리지 않는지를 남긴다.

faircast의 실패 지점은 빌드 오류가 아니라 **사실 오류**다. 그래서 이 문서가 있다.

---

## 1. 도구 제약 — 먼저 알 것

| 도구 | 상태 |
|---|---|
| `web_fetch` → **faircast.kr** | **차단.** Wordfence. 자기 사이트를 못 읽는다 |
| `web_fetch` → fairwayeta.com | 정상 |
| `web_search` | 정상. 다회 검색 전제 |
| 대표의 화면 붙여넣기 | **가장 확실.** 관청 페이지·표 이미지는 이 경로가 최선 |

관청 사이트는 자동 조회가 자주 막히거나 JS 렌더다. **대표에게 화면을 요청하는 것이 빠르다.**

---

## 2. 1차 출처 우선순위

1. **법령·시행령** (국가법령정보센터) — 명칭·등급·관할의 최종 근거
2. **해양수산부 / 지방해양수산청** 보도자료·항만현황 페이지
3. **한국선급(KR)** 문서 — 검사·규칙 용어의 한국 통용어
4. **IMO / IACS** 원문 — 단, 직역하지 말고 3번으로 한국 용어 대조
5. **DART 공시 / 회사 IR** — 회사 발표 수치
6. 업계 매체 — **교차 확인용으로만.** 기자 해석을 수치로 옮기지 않는다

---

## 3. 확인된 사실 (재조사 금지)

| 항목 | 값 | 근거 |
|---|---|---|
| 무역항 총수 | **31** (국가관리 14 + 지방관리 17) | 항만법 시행령 |
| 「12개 무역항」 | **틀림** | 위 |
| 묘박지 표의 톤수 단위 | **GT** (DWT 아님) | 지방해양수산청 항세도 |
| 자개항 / 조약항 | 서로 다른 개념. 혼용 금지 | — |
| 새만금항 명칭 시행령 개정 | **미확정.** 재입법예고 7/27 종료, 국무회의 의결 여부 미확인 | 발행 전 재확인 |

---

## 4. 용어 대조표 (직역하면 현업이 즉시 알아챈다)

| 영문 | **한국 통용어** | 틀린 직역 |
|---|---|---|
| Special Survey | **정기검사** | Normal Survey / 특별검사 |
| CSM | **계속검사** | 계속기관검사 |
| Predictive Maintenance | **예측정비** (해수부 표준) | 예지정비 |
| credit (검사) | **검사 갈음** | 검사 크레딧 |
| oil analyzer | **오일 분석기** | 유분석기 |
| edge computing | **엣지 컴퓨팅** | 에지 컴퓨팅 |
| purifier 정비 | **청정기 정비** | 청정기 서비스 |

**판정 기준: 네이버 뉴스·한국선급 문서·해사법규 교과서에서 검색되는 표현인가.**

약어 첫 등장은 `한국어(약어, 영문 풀네임)` — 예: 계획정비제도(PMS, Planned Maintenance System).

---

## 5. 톤수 단위 — 상습 사고 지점

| 약어 | 정체 | 쓰이는 곳 |
|---|---|---|
| **GT** | 총톤수 (부피 기반) | 묘박지 수용력, 검사·규정 적용 기준, 항비 |
| **DWT** | 재화중량톤수 (실을 수 있는 무게) | 선박 크기 비교, 용선 |
| NT | 순톤수 | 통항료·항비 |
| TEU | 컨테이너 개수 | 컨테이너선·물동량 |

**표를 인용할 때 단위 칸을 먼저 읽는다.** 군산항 초안이 여기서 두 번 틀렸다.

---

## 6. 출처 표기 규칙 (지침 [11] 요약 — 실전형)

- 한 줄로 **2~3개**. 4개 이상 나열은 AI 크롤링 단서
- 회사명·단체명은 **본문에서 그 주체를 직접 다룰 때만**
- 그 외엔 우회: 「관련 기관 자료」, 「업계 자료」, 「한국 보도에 따르면」
- 매체 실명(매일경제·한국경제 등) 직접 인용 회피
- **인용구(따옴표) 0개.** 모든 데이터는 자체 표현으로 재구성
- 좋은 예: `출처: IMO ISM Code · IACS 통합규칙, 한국선급(KR), 해양수산부`

---

## 7. 조사 절차 교훈

- **관청 표는 이미지로 받아 눈으로 읽는다.** 텍스트 추출은 단위 칸을 날린다
- **기자 해석을 수치로 옮기지 않는다.** (예: 「전 선대 109척」은 기자 해석, 실제는 「40척 계약 + 확대 방침」)
- **영문판 데이터를 한글판에 그대로 쓰지 않는다.** 분기 데이터는 시점이 어긋난다
- **「근본 원인을 찾았다」고 선언하지 않는다.** v5·v6에서 두 번 선언했다가 두 번 뒤집혔다
- 「한국어 자연성 95%」같은 추상 점수를 쓰지 않는다. **문장 단위로 지적한다**

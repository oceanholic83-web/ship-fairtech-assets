## 0-1. 2026-08-24 작업분 (일주일 전)

### 검색 색인 — 원인을 찾았다

`docs/INDEXING_DIAGNOSIS.md` 신설. 발행 64편 중 **색인 18편**.

**글 자체는 문제가 아니었다.** 색인된 글과 안 된 글의 본문 길이·요약·카테고리·내부 링크가 사실상 같다.
(미색인 쪽이 오히려 길고 링크도 많다.) 「얇아서 안 들어갔다」는 설명은 성립하지 않는다.

실제로 찾은 것 둘:

- **noindex 카테고리 11개가 사이트맵에 실려 있었다.** 「색인하지 마라」와 「색인해 달라」를 동시에 보냈다.
  → 스니펫 361을 `Exclude Tags & Categories from Sitemap`으로 확장. 사이트맵 **83 → 72 URL**. 해소.
- **lastmod이 단 두 날짜(8/23 51편, 8/4 13편)에 몰려 있다.** 일괄 치환이 전 글의 수정 시각을 밀어버렸다.
  전면 개고 4편이 오타 고친 47편과 구분되지 않는다. **되돌릴 수 없다.**

⭐ **규칙 신설 — 일괄 치환은 수정 시각을 건드리지 않는다.**
표현 통일·오타 같은 비실질 편집은 REST 요청에 원래 `modified` 값을 같이 넣어 보존한다.
실질 개고만 수정 시각을 갱신해야 「이 글이 바뀌었다」가 신호로 작동한다.

**색인 요청 9건 완료** — 발견-미색인 5편 + 8월 전면 개고 4편. 하루 약 10건 한도.
404·리디렉션·noindex·robots 차단 항목은 **전부 정상 상태이며 재검토 요청 대상이 아니다.**
「소스 = Google 시스템」인 항목은 요청 버튼 자체가 없다. 재크롤에 1~2주.

### OG 메타 — 스니펫 823 신설

전 페이지에 `og:description` 하나뿐이었고 `og:title`·`og:url`·`og:type`·`og:site_name`·`og:locale`이 전부 없었다.
링크를 공유하면 제목 없는 회색 박스로 떴다.

**WPCode 823 `fc-og`** (PHP · 어디서나 실행 · `wp_head` 우선순위 4). 원본 `docs/wpcode/fc-og.php`.
제목·URL·FIFU URL에서 자동 파생한다. **SEO 플러그인을 쓰지 않은 이유는 글마다 입력칸이 생기기 때문**이다.
Kadence의 `og:description`과 FIFU의 글 이미지는 건드리지 않는다 — 중복 태그 0건 확인.
랜딩 4개 페이지(269 · 488 · 490 · 522)에 대표이미지도 붙였다.

### 이미지 — 미디어 라이브러리 참조 0건 달성

초기 10편이 가비아 미디어 라이브러리에 PNG를 직접 올려 쓰고 있었다(지침 [9] 위반 상태).
브라우저에서 WebP 변환(1600px, q82) → `faircast-images` 레포 → jsDelivr. **약 18MB → 약 0.8MB.**
alt 텍스트 10건도 새로 작성.

**태그 이력:** v5(벌크선 도식 2) · v7(초기 히어로 10) · v8(만재흘수선 3)

⚠️ **47번 「LNG선 30년 독점사」의 대표 사진은 구형(모스형) 탱크 LNG선이다.**
이미지 규칙상 LNG는 원통형 완전방호식이고 구형은 LPG다. 그 글 개고 시 교체 대상.
⚠️ **510번(한진해운 붕괴)** alt 비어 있음. 이번 건과 무관하게 원래 없던 것.

### 글쓰기 — `docs/WRITING_CHECKLIST.md` 신설

**독자가 멈추는 자리** 체크리스트. 만재흘수선 초안이 약어(WNA)·인물(플림솔)·어려운 낱말(흠결)·
개념 정의(건현) 넷에서 모두 걸린 게 계기다.

판정 기준 한 줄: **이 글을 처음 읽는 사람이 어디에서도 멈추지 않고 끝까지 갈 수 있는가.**
발행 전 훑기 10항목 포함. **앞으로 모든 글에 적용한다.**

## 2. 작업 방식 (대표 지침 요약 — 전문은 claude.ai 프로젝트 지침 v7)

- 반말. 무조건 긍정 금지, 문제는 냉정하게 지적

- 오더는 파일 1~2개 / 변경 2~3곳 단위로 쪼개서 Cursor Auto로. 디버깅·리팩터·아키텍처만 Claude Code
- 각 오더 끝에 **검증 명령어**(grep / build)를 넣는다
- 운영자 신상 노출 금지. 대외적으로 운영자는 「Fairtech」 팀
- **링크 주소는 항상 풀로 적는다**
